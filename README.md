# 🎯 Algorithm Interactive Visualizer & Code Tracer

코딩 테스트 및 알고리즘 인터뷰 대비를 위한 **인터랙티브 알고리즘 실행 트레이서**입니다.

## 🚀 Live Demo
- **GitHub Pages**: [https://acha21.github.io/algo-visualizer/](https://acha21.github.io/algo-visualizer/)

## ✨ Key Features
- **LaTeX Mathematical Invariants**: 핵심 수학적 불변식 및 시간복잡도 표기
- **Line-by-Line Code Highlighting**: 파이썬 코드 실행 라인 1:1 동기화 및 펄스 하이라이팅
- **Memory State Animation**: 포인터(L, Mid, R) 및 배열 메모리 카드 상태 애니메이션
- **Live Variable Watcher**: 실행 중 변수값 및 조건 분기 결과 실시간 추적
- **Interactive Controls**: 자동 재생(Auto-play), 스텝 전진/후진, 슬라이더 타임라인 탐색
