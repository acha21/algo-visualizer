이진 탐색 (Binary Search)

코드 라인 번호와 배열 메모리 상태(L, R, Mid)의 1:1 동기화 실행 트레이서

수학적 불변식: Target ∈ [nums[L], nums[R]]
중간값 계산: mid = ⌊ (L + R) / 2 ⌋
시간 복잡도: T(N) = O(log N)
📥 Input
nums: list[int] = [1, 3, 5, 7, 9, 11, 13] | target: int = 9
(※ 오름차순 정렬 배열)
📤 Desirable Output
int = Index 4 (값: 9)
(미존재 시: -1)
Python Algorithm Code Line 2
1 def binary_search(nums: list[int], target: int) -> int:
2 left, right = 0, len(nums) - 1
3 while left <= right:
4 mid = (left + right) // 2
5 if nums[mid] == target:
6 return mid
7 elif nums[mid] < target:
8 left = mid + 1
9 else:
10 right = mid - 1
11 return -1
